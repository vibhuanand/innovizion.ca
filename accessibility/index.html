Accessibility

A website designed to be readable, navigable and usable across devices and access needs.

Our approach

We aim to make this website accessible and use WCAG 2.2 Level AA as a design and implementation target. This statement is not a claim of independent certification or a complete accessibility conformance report.

Features

  • Semantic headings, page landmarks and descriptive navigation.
  • A skip link, visible focus indicators and keyboard-operable controls.
  • Responsive layouts that support text resizing and browser zoom.
  • Labelled fields, inline errors and an error summary for the enquiry builder.
  • Reduced-motion support and no autoplay media.
  • A capability statement with a dedicated print layout.

Known limitations

The enquiry builder and print button use JavaScript. Direct email links and the browser’s own Print command remain available without JavaScript. Opening an email draft also depends on your device’s configured email application; copying the message provides an alternative. English is the currently published language.

Report a barrier or request another format

Please email vibhuanand@outlook.com with the page address, a description of the issue and the format or assistance you need. If useful, include your browser and assistive technology. Do not include sensitive project information.
